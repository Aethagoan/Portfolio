Space Guild Project

A browser-based space game built with a Python backend. Players navigate the cosmos, upgrade their ships, battle across a shared world, and build a legacy among the stars.

View source on GitHub ↗

What I built

The project combines a FastAPI backend with a lightweight web client. The backend models locations, ships, factions, items, and player actions, while the client provides a terminal-inspired interface for exploring the game world.

Highlights

  • Designed a shared game world with locations, factions, ships, and items.
  • Built API workflows for movement, combat, scanning, and player actions.
  • Added automated tests for game behavior, concurrency, and scalability.
