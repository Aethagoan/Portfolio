SpaceWars

A C# console client for the SpaceWars coding challenge. I won the competition with this project by combining game-state discovery, web scraping, and trigonometry.

View source on GitHub ↗

The approach

The game did not expose an obvious endpoint for enemy positions, so I inspected the game HUD and scraped the page with injected JavaScript. Those positions fed an aiming routine that used simple trigonometry to point and fire automatically.

Result

The bot could target enemies with a single input and finished with roughly ten times the score of the next competitor.
